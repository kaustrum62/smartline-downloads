# SmartLine downloads

Download the current [SmartLine 0.14.9 Windows installer](https://github.com/kaustrum62/smartline-downloads/releases/download/v0.14.9-rc1/SmartLine-0.14.9-Setup-x64-unsigned.exe).

No GitHub sign-in is required. This unsigned candidate removes the AKMS pressure-zero startup error and shows automatic guidance only for a newly identified AKMS connection. Starting a scan still requires pressure-zero calibration.

Read the [release notes and checksum](https://github.com/kaustrum62/smartline-downloads/releases/tag/v0.14.9-rc1) before installing. Earlier connection reliability and physical multi-PC/AKMS/soak qualification remain separate outstanding work.

The editable SmartLine source is kept in a separate private repository.
