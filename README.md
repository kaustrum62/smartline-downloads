# SmartLine downloads

Download the current [SmartLine 0.15.5 Windows installer](https://github.com/kaustrum62/smartline-downloads/releases/download/v0.15.5-rc1/SmartLine-0.15.5-Setup-x64-unsigned.exe).

No GitHub sign-in is required. This unsigned candidate fixes the Active Run notes/events panel and adds timestamped event markers to active and saved-run charts. General notes remain in the table without chart markers. Device storage now reports buffered records.

Read the [release notes and checksums](https://github.com/kaustrum62/smartline-downloads/releases/tag/v0.15.5-rc1) before installing. Existing hub firmware 0.6.10 remains compatible; no flash is required for this update. Intermittent Bluetooth discovery and remaining hardware qualification are separate limitations.

The editable SmartLine source and research data are kept separately; this repository distributes public binaries only.
