# SmartLine downloads

Download the current [SmartLine 0.15.4 Windows installer](https://github.com/kaustrum62/smartline-downloads/releases/download/v0.15.4-rc1/SmartLine-0.15.4-Setup-x64-unsigned.exe).

No GitHub sign-in is required. This unsigned candidate fixes startup/tray freezes with large workspaces and moves database backups and requested historical calculations off the UI thread.

Read the [release notes and checksums](https://github.com/kaustrum62/smartline-downloads/releases/tag/v0.15.4-rc1) before installing. Intermittent Bluetooth discovery errors and sensor/hardware qualification remain separate limitations. The optional N32R16V firmware is the existing 0.6.10 candidate.

The editable SmartLine source and research data are kept separately; this repository distributes public binaries only.
