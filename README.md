# SmartLine downloads

Download the current [SmartLine 0.15.6 Windows installer](https://github.com/kaustrum62/smartline-downloads/releases/download/v0.15.6-rc1/SmartLine-0.15.6-Setup-x64-unsigned.exe).

No GitHub sign-in is required. This unsigned candidate adds bounded recovery for the initial Windows GATT discovery error when reconnecting to a remembered hub, using the existing pairing. It includes the saved note/event panel and timestamped chart markers from 0.15.5.

Read the [release notes and checksums](https://github.com/kaustrum62/smartline-downloads/releases/tag/v0.15.6-rc1) before installing. Hub firmware 0.6.10 remains compatible; no flash is required. This change does not establish universal radio/hardware qualification.

The editable SmartLine source and research data are kept separately; this repository distributes public binaries only.
