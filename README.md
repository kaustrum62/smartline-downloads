# SmartLine downloads

Download the current [SmartLine 0.14.10 Windows installer](https://github.com/kaustrum62/smartline-downloads/releases/download/v0.14.10-rc1/SmartLine-0.14.10-Setup-x64-unsigned.exe).

No GitHub sign-in is required. This unsigned candidate adds an explicit Stop unmatched hub capture action when the Hub still reports an active capture but the controller has no Active Run. After stopping it, use Allow another computer to open enrollment. Readings, settings and pairings are retained. No firmware update is required for this correction.

Read the [release notes and checksum](https://github.com/kaustrum62/smartline-downloads/releases/tag/v0.14.10-rc1) before installing. Earlier BLE reliability and physical multi-PC/AKMS/soak qualification remain separate outstanding work.

The editable SmartLine source is kept in a separate private repository.
